# 한능검 퀘스트 보드

한국사능력검정시험 공부를 게임처럼 기록하는 웹 페이지입니다. 퀘스트를 체크하면 경험치(XP)가 쌓이고, 레벨이 오르고, 보스를 클리어합니다. 휴대폰 홈 화면에 앱처럼 설치해서 쓸 수 있고(PWA), 서버가 필요 없습니다.

**바로 써 보기:** https://2rachel2.github.io/3/

## 주요 기능

- **오늘의 퀘스트:** 퀘스트를 추가하고 이름과 XP를 직접 정합니다. 체크하는 즉시 XP를 받고, 그날 퀘스트를 모두 끝내면 올클리어 보너스가 들어옵니다.
- **포모도로와 연속 출석:** 25분 집중 한 세트마다 XP를 받고, 연속 출석 7일마다 보너스를 받습니다.
- **레벨과 시험 D-day:** 시험일과 목표 등급(1급~6급)을 정하면 D-day가 계산됩니다. 레벨표의 필요 XP와 목표 시기는 직접 고칠 수 있습니다.
- **시대별 보스 맵:** 시대별 기출을 풀고 "도전 중"을 눌러 클리어하면 XP를 받습니다. 맞힌 개수와 전체 문항 수를 보스마다 따로 적습니다.
- **인물 캐릭터 도감:** 이름을 보고 업적을 떠올린 뒤 카드를 넘겨 확인하는 암기용 도감입니다. 인물은 직접 추가할 수 있습니다.
- **약점 몬스터 도감:** 틀린 문제를 적으면 1차(다음 날), 2차(3일 뒤) 복수 날짜를 정해 줍니다. 두 번 연속 맞히면 정복하고 XP를 받습니다.
- **기출 기록과 주간 보상:** 점수와 걸린 시간을 기록하고, 주차별 목표를 달성하면 내가 정한 보상을 받습니다. 주차 기간도 바꿀 수 있습니다.

## 쓰는 방법

1. 위 주소를 열고 오늘 탭에서 시험일과 목표 등급을 정합니다.
2. 아침에 오늘의 퀘스트를 확인하고, 끝낼 때마다 체크합니다.
3. 틀린 문제는 약점 도감에 적고, 알려 주는 날짜에 복수전을 합니다.
4. 기출을 풀 때마다 기록에 점수를 남깁니다.

## 휴대폰에 앱처럼 설치하기

GitHub Pages 주소(https)로 열어야 설치할 수 있습니다.

- **아이폰(사파리):** 주소를 열고 아래 공유 버튼 → `홈 화면에 추가`를 누릅니다. 크롬이나 다른 브라우저가 아니라 사파리에서 해야 합니다.
- **안드로이드(크롬):** 주소를 열고 오른쪽 위 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

설치하면 홈 화면 아이콘으로 열리고, 한 번 열어 본 뒤에는 인터넷이 없어도 실행됩니다. 글꼴은 처음 한 번 인터넷으로 받아 둡니다.

## 저장 방식

- 기록은 쓰는 기기의 브라우저에만 저장됩니다. 서버로 전송되지 않고, 다른 기기에서 열면 새로 시작합니다.
- 브라우저의 사이트 데이터를 지우거나 시크릿 모드로 열면 기록이 사라질 수 있습니다.

## 기술

- 순수 HTML, CSS, JavaScript로 만들었고 빌드 과정이 없습니다. 앱 설치와 오프라인 실행은 `manifest.webmanifest`와 `sw.js`(서비스 워커)가 맡습니다.
- 글꼴만 Google Fonts에서 불러오며, 그 외 외부 서비스는 쓰지 않습니다.
